# VoidcoreAdvisor Remix

A revised remix version of the VoidcoreAdvisor addon for World of Warcraft. It hooks into the Encounter Journal to show which loot specialization gives you the best odds of getting your desired items when spending Nebulous Voidcores.

## ⚠️ Notice
This Remix edition fixes several features of the original addon, but unfortunately some functionality is no longer maintained and may be broken or unavailable. It is provided as-is for players who still find it useful.

## 🔗 Original Project
This addon is based on the original work by **rolferik12**. 
Please check out the original repository here:
[https://github.com/rolferik12/VoidcoreAdvisor](https://github.com/rolferik12/VoidcoreAdvisor)

## 📦 Installation
1. Download the latest release or clone this repository.
2. Extract the `VoidcoreAdvisorRemix` folder into your WoW `Interface/AddOns` directory.
3. Restart the game or type `/reload` in-game.

# VoidcoreAdvisor Remix

魔兽世界插件 VoidcoreAdvisor 的修订 Remix 版。它接入冒险指南（Encounter Journal），显示消耗 Nebulous Voidcores 时，哪个拾取专精获得目标物品的几率最高。

## ⚠️ 注意事项
此 Remix 版修复了原版插件的部分功能，但遗憾的是，仍有一些功能已不再维护，可能失效或不可用。它按现状提供给仍觉得有用的玩家。

## 🔗 原版项目
本插件基于 **rolferik12** 的原版作品制作。
请在此处查看原版仓库：
[https://github.com/rolferik12/VoidcoreAdvisor](https://github.com/rolferik12/VoidcoreAdvisor)

## 📦 安装方法
1. 下载最新版本或克隆此仓库。
2. 将 `VoidcoreAdvisorRemix` 文件夹解压到你的魔兽世界 `Interface/AddOns` 目录中。
3. 重启游戏或在游戏内输入 `/reload`。
